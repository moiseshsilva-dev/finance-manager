# Sprint 01 - Documentação Inicial

## Informações gerais
- **Projeto:** Finance Manager
- **Sprint:** 01
- **Período:** 12/10/2026 a 25/10/2026
- **Duração:** 14 dias
- **Responsável:** Desenvolvedor do projeto
- **Capacidade estimada:** 6 a 10 horas
- **Ferramenta de gerenciamento:** GitHub Projects

## Sprint Goal
Estabelecer a base documental e técnica do Finance Manager, consolidando a visão do produto e preparando sua estrutura para um desenvolvimento organizado, incremental e independente do ambiente de desenvolvimento.

Ao final da Sprint, o projeto deverá possuir documentação inicial revisada, estrutura Maven configurada e processo de build validado tanto pelo IntelliJ IDEA quanto pelo terminal.

## Sprint Backlog
A Sprint 01 contempla a preparação documental e técnica do Finance Manager, organizando as atividades em cinco issues acompanhadas pelo GitHub Projects.

- [x] **FM-01 - Initial Project Documentation:** Elaborar e revisar a documentação inicial do projeto.
- [x] **FM-02 - Migrate Project Structure to Maven:** Reorganizar a estrutura de diretórios conforme as convenções do Maven.
- [x] **FM-03 - Create and Configure Maven POM:** Criar e configurar o arquivo `pom.xml`.
- [x] **FM-04 - Validate Maven Build:** Validar a compilação e o empacotamento do projeto pelo Maven, no terminal e no IntelliJ IDEA.
- [ ] **FM-05 - Sprint Review and Delivery:** Revisar as entregas, verificar os critérios de conclusão e registrar os resultados da Sprint.

## Definition of Done
Uma entrega da Sprint 01 será considerada concluída quando:

- Atender aos critérios de aceitação definidos na respectiva issue.
- Ter suas alterações revisadas quanto à consistência e à organização.
- Não apresentar erros conhecidos que comprometam o objetivo da entrega.
- Estar devidamente versionada no Git.
- Ter suas alterações publicadas no repositório remoto do GitHub.
- Ter sua issue atualizada no GitHub Projects.

Para as entregas técnicas, também será necessário validar os comandos e comportamentos previstos nos respectivos critérios de aceitação.

## Sprint Review

### Entregas realizadas

- Documentação inicial do projeto criada e organizada.
- Estrutura de diretórios migrada para o padrão Maven.
- Arquivo `pom.xml` criado e configurado.
- Build Maven executado e validado pelo terminal e pelo IntelliJ IDEA.
- Compilação das classes Java confirmada por meio dos arquivos gerados em `target/classes`.

### Avaliação do Sprint Goal

O objetivo da Sprint foi alcançado, estabelecendo a base documental e técnica necessária para a continuidade do desenvolvimento do Finance Manager.

As entregas técnicas previstas foram concluídas antes do encerramento do período planejado.

### Pendências

Não foram identificadas pendências técnicas que impeçam a conclusão do Sprint Goal.

## Sprint Retrospective

### Pontos positivos

- Aprendizado prático sobre Maven, estrutura de projetos Java e versionamento.
- Processo de desenvolvimento produtivo e organizado.
- Uso do GitHub Projects para acompanhamento das atividades e visualização das próximas entregas.
- Mentoria passo a passo contribuindo para a compreensão das ferramentas e dos conceitos utilizados.

### Pontos de melhoria

- Algumas issues apresentaram atividades redundantes ou muito relacionadas entre si.
- O esforço real de determinadas atividades superou as estimativas iniciais.

### Ações para a próxima Sprint

- Priorizar issues que representem entregas verificáveis, evitando fragmentação excessiva.
- Considerar o tempo de aprendizado nas estimativas de esforço.
- Manter a orientação passo a passo nas configurações e nos conceitos novos, proporcionando maior autonomia durante a implementação de código.
- Avaliar a eficácia dessas mudanças na próxima retrospectiva.
